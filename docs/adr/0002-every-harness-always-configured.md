# Every Harness is configured at all times; there is no "active harness"

Sync writes links, agent files and model settings for Claude Code, Codex and OpenCode on every run, so choosing a backend in T3 Code needs no Overlord step. We dropped the earlier "active vendor" idea, together with the `overlord code`/`oc` terminal shortcut and harness desktop apps at startup, because the user works only through T3 Code and switching must be instant.
